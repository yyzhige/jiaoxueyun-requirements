# 给 QA 的说明

1. 每个模块至少覆盖主流程、空状态、错误状态、权限拒绝和上下文切换。
2. P0 端到端用例必须从学校选择开始，到学生订正和提升计划证据结束。
3. 主观题未经教师确认不得发布；AI 不可用时人工路径必须可完成。
4. 学生只能查看本人已发布数据；任课教师、班主任和教务的结果集必须不同且符合职责。
5. 成绩修正、计划调整、组织变更和 AI 执行需要验证审计记录。
6. 每个选择型字段至少验证默认值、无可选项、加载失败、搜索无结果、父项变化、权限收缩、停用历史值和提交时重新校验。
7. 固定枚举断言稳定 code，主数据断言对象 ID 与显示快照；不得只断言中文 label。
8. 按 Flow ID 建立跨模块用例，断言输入版本、目标版本、Owner 交接、学生可见性和审计引用。
9. 批量流必须验证对象级部分成功与只重试失败项；重复请求必须验证幂等，不重复生成版本、通知或任务。
10. 当前评审清单验证的是需求可测性，不代表运行态或实现证据已经存在。
