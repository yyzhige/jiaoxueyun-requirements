# 给设计与前端架构的说明

1. 当前先评审页面载体、信息层级、状态覆盖、跨端差异和 Prototype ID，不开始生产代码。
2. 学生 App 与教师 Web 共享业务状态，但不能直接复制同一页面结构。
3. 作业创建、AI 复核、成绩册和学生管理属于高频工作台，优先保证扫描、比较和连续操作效率。
4. AI 对话是业务能力入口，不是覆盖业务页面的独立聊天产品；面板不得遮挡关键数据。
5. 所有高风险操作必须有结构化预览、明确影响对象和确认动作。
6. 所有下拉、单选、多选、级联和自动完成必须引用 `field-option-catalog.md` 的 Field ID 与 Option Set，不从线框文案临时推导选项。
7. 原型必须覆盖默认、加载、无选项、搜索无结果、权限收缩和历史失效值；停用值显示名称快照但不能新选。
8. 产品确认后再讨论设计系统、组件映射、响应式规则和实际技术栈。
