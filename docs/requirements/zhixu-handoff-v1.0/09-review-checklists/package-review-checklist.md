## 5. 产品确认方式

产品负责人对每个开放决策选择默认建议、提出修改或明确延期。Data Owner、学校配置 Option Set 和 P0 Flow 门禁需要同步确认。确认结果应回写模块 PRD、中央合同和开放决策表；未确认项不能靠原型或技术方案替代。
