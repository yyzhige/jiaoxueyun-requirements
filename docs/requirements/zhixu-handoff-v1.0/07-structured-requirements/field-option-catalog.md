# 字段与选项字典

本文件是所有下拉、单选、多选、级联选择、自动完成、分段控件和选择菜单的中央事实源。模块 PRD 与线框只引用 Field ID 和 Option Set，不重复定义同一组选项。

## 1. 选项合同规则

1. 固定枚举保存稳定 `code` 和显示 `label`；修改 label 不修改历史 code。
2. 主数据选项保存对象 ID 与当时显示名快照；对象停用后历史记录继续显示“名称（已停用）”，但新建和修改时不可再选。
3. 权限范围选项必须在服务端按当前学校、身份、学期和授权重新过滤，前端隐藏不构成权限控制。
4. 级联父字段变化时清空所有不再合法的子字段；存在未保存内容时先提示影响。
5. 没有可选项时显示原因和解决入口，不自动放宽到全校、全学科或全部学生。
6. 默认值只能缩小操作范围，不能默认扩大权限或批量影响范围。
7. 加载失败保留已选值但禁止提交；搜索无结果与接口失败使用不同状态。
8. 固定枚举新增 code 可以向后兼容；删除、合并或改变含义必须形成版本并评估历史数据。

## 2. 控件类型

| 控件 | 使用条件 |
|---|---|
| 单选下拉 | 选项稳定、数量中等、只允许一个值 |
| 多选下拉 | 允许多个值且需要显示已选摘要 |
| 级联选择 | 子项合法性依赖父项，如地区、年级与班级 |
| 自动完成 | 选项数量大，需要搜索，如学校、教师、学生、作业 |
| 分段控件 | 2-4 个高频且互斥的固定选项 |
| 单选卡片 | 选项需要同时展示身份、范围或解释 |
| 复选框 / 开关 | 是 / 否配置，不使用文字下拉 |
| 日期 / 时间选择 | 值来自日历或时间规则，不作为自由文本 |
| 动作菜单 | 选项代表命令而非数据值，仍需权限与可用状态 |

| OPT-COM-021 | 学校允许日期时间 | 当前学期校历、工作日、节假日和学校禁用时段 | 无默认，显示用户本地时区 | 日期时间必须满足业务起止规则；历史时间不因校历变化而重写 |

## 7. 产品评审与验收

1. 原型中出现新的选择控件时，必须先新增 Field ID 或引用已有 Field ID。
2. 前端 Mock 数据必须使用 Option Set 的稳定 code，不得只保存中文 label。
3. 后端接口返回停用主数据时必须附带停用状态和显示快照，不能返回空名称。
4. QA 至少覆盖默认值、无选项、加载失败、权限收缩、父项变化、停用历史值和多选清空七类场景。
5. 石家庄目标学校尚未确认的排课、激活和 CLI 细项以“学校配置”来源表达，不伪造跨校统一规则。
