## 2. 关键业务规则

1. 计划候选来自可解释的知识点证据、作业表现、订正结果或教师人工建议。
2. AI 可生成目标、任务和周期草稿，但对应任课教师确认后才成为学科计划。
3. 每个学科目标必须有负责人、证据来源、成功条件、周期和评估时间。
4. 班主任查看全学科目标、每日任务总量、截止冲突和学生反馈。
5. 班主任可调整优先级、时间和总量建议；修改学科内容必须回到对应任课教师确认。
6. 计划生效前展示学生每日预计用时和同时进行的重点目标数量。
7. 学生可反馈不会做、任务过多、内容重复或设备问题；反馈同步任课教师和班主任。
8. 完成任务只产生执行证据，不自动证明知识点已掌握。
9. 后续表现触发调整建议，不能静默修改正式计划。
10. 计划历史版本、责任人和调整原因必须保留。

## 5. 需求章节

### 5.1 提升候选与学科计划

- 候选显示证据摘要和产生原因，教师可以进入 INS-001 查看完整证据。
- 生成草稿时选择目标、周期、每日任务、阶段测验和成功条件。
- 任务类型可包括错题再练、知识点微练习、阅读 / 背诵、教师指定材料和阶段测验。

### 5.2 班主任全科协调

- 按日历显示未来 7 / 14 天各学科任务和预计总时长。
- 冲突包括同日任务过多、重点目标过多、与正式作业截止冲突和学生反馈负担过重。
- 班主任协调形成建议，不直接改写学科题目、讲解或成功条件。

### 5.3 学生执行

- 学生首页显示今日提升任务、预计用时、进度和原因的通俗说明。
- 学生可暂停并提交困难反馈；暂停是否改变截止由教师决定。
- 完成后记录提交、练习结果或完成证明，并同步责任教师。

### 5.4 评估与调整

- 评估综合计划前后证据，不只看任务完成率。
- 系统提出保持、降低 / 提高难度、延长、完成或转人工辅导建议。
- 教师决定后生成新版本，班主任看到全科摘要变化。

## 6. 权限矩阵

| 能力 | 任课教师 | 班主任 | 学生 |
|---|---|---|---|
| 查看本学科候选 | 是 | 全科摘要 | 本人已生效计划 |
| 编辑学科目标与任务 | 是 | 仅兼任学科 | 否 |
| 调整全科优先级 / 时间建议 | 查看 | 是 | 反馈困难 |
| 使计划生效 | 对本学科确认 | 协调后查看 | 否 |
| 完成 / 调整评估 | 本学科 | 全科查看 | 查看结果 |

## 7. 异常与边界

| 场景 | 处理 |
|---|---|
| 学科无有效任课教师 | 候选不生成正式计划，进入教务待处理 |
| 多学科同时生成 | 先进入班主任协调，不直接全部生效 |
| 学生长期未执行 | 生成事件提醒，不自动加码任务 |
| 证据状态被教师修正 | 标记计划依据变化，提出重新评估 |
| 任课教师变更 | 新教师接管当前计划需确认，历史责任人保留 |

## 8. 验收与评估

| ID | 验收标准 |
|---|---|
| PLN-AC-01 | 每个提升候选能追踪到具体证据。 |
| PLN-AC-02 | 学科计划必须由对应任课教师确认后生效。 |
| PLN-AC-03 | 班主任能查看全科任务量和冲突。 |
| PLN-AC-04 | 班主任不能越权修改他科学科内容。 |
| PLN-AC-05 | 学生反馈困难同步任课教师与班主任。 |
| PLN-AC-06 | 完成任务不自动判定知识点已掌握。 |
| PLN-AC-07 | 系统调整建议不自动修改正式计划。 |
| PLN-AC-08 | 计划版本、责任人和调整原因可审计。 |

评估指标：候选到确认转化率、每日任务超量率、学生完成率、困难反馈处理时长、再验证通过率。

## 数据责任与选择型字段合同

- 权威对象：`DAT-PLN-01` 至 `DAT-PLN-05`，覆盖候选、学科计划、任务、全科协调和评估。
- Owner 边界：每个学科提升点由对应任课教师确认并持续同步；班主任只拥有 `DAT-PLN-04` 全科协调记录。
- 选择型字段：`PLN-F001` 至 `PLN-F010`，覆盖学生、学科、知识点、优先级、来源、负责人、任务类型、状态、评估和协调班级。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-008`、`DF-009`、`DF-010`、`DF-011`、`DF-012`、`DF-013`，核心为 `DF-011` 候选到学科计划与协调、`DF-012` 学生执行与评估。
