## 2. 业务目标与非范围

目标：教师在一个连续流程内创建可被学生正确理解、提交、批改和发布反馈的作业，且系统在发布前暴露缺失规则和影响范围。

非范围：完整试题版权库、复杂组卷算法、联考卷管理、课堂直播任务、学生社交互评。

## 3. 关键业务规则

1. 作业必须绑定当前学校、学期、课程、学科、教师和至少一个有效班级。
2. 教师只能选择当前有效任课关系覆盖的班级和学科。
3. 作业类型决定学生提交载体：在线题、拍照页、混合或完成型学习任务。
4. 每道计分题必须有分值；需要 AI 辅助的题必须有答案、评分点或人工确认规则。
5. 主观题默认进入教师复核，不允许配置为无教师确认自动发布。
6. 截止、补交、重提和迟交标记在发布前确定，并在学生开始前可见。
7. 多班发布使用同一作业定义，但每班提交、批改与发布状态独立。
8. 发布前展示班级人数、题目数、总分、预计用时、提交方式、截止和反馈规则。
9. 发布后修改题目、分值、评分规则或班级范围必须形成新版本并提示已有提交影响。
10. AI 生成题目、答案或评分点必须标记来源，教师确认后才进入作业。

## 5. 状态与流程

```text
新建草稿
→ 选择班级与类型
→ 编辑内容
→ 配置评分与反馈
→ 系统校验
→ 教师预览
→ 发布
→ 各班独立进入进行中
```

| 状态 | 可编辑范围 | 可执行操作 |
|---|---|---|
| 草稿 | 全部 | 保存、删除、预览、发布 |
| 待发布 | 全部 | 继续编辑、发布 |
| 进行中且无提交 | 允许受控修改 | 修改需提示学生 |
| 进行中且已有提交 | 不允许静默改题 / 改分 | 创建新版本或仅改说明 |
| 已截止 | 仅补交和批改设置 | 延期需记录原因 |

## 6. 需求章节

### 6.1 作业基本信息

- 默认带入当前教师最近使用的课程和班级，但发布前必须再次确认。
- 多班选择展示每班学生数和任课关系状态；失效班级不可选择。
- 预计用时由教师填写或根据题目建议，学生端展示为参考值。

### 6.2 内容与提交方式

- 在线题按题呈现并自动保存；拍照作业定义要求页数、页序或自由页数。
- 混合作业可同时包含在线题和拍照页；学生提交时显示两部分完成度。
- 学习任务必须定义完成证据，例如阅读记录、背诵确认或实验材料，不默认计分。

### 6.3 评分与反馈

- 客观题可配置标准答案；多选题配置全对 / 部分得分规则。
- 过程题配置关键步骤与人工复核；开放题配置评分点和评语要求。
- 答案、解析和教师评语分别配置对学生的开放时点。

### 6.4 预览与发布

- 教师预览学生视角，检查标题、内容、提交方式、截止、分值和反馈。
- 校验阻断项：无班级、无内容、分值不一致、缺评分规则、截止非法。
- 发布是高影响操作，展示人数和通知范围，但不需要二次密码。

## 7. 权限、异常与刷新

| 场景 | 处理 |
|---|---|
| 班级任课关系在编辑中失效 | 阻断发布并要求移除班级 |
| 内容导入失败 | 保留已成功内容，展示逐项错误 |
| AI 生成失败 | 保留人工编辑能力，不阻断保存草稿 |
| 发布请求部分失败 | 不形成部分班级静默发布；展示成功 / 失败明细并允许重试 |
| 离开未保存 | 提示保存草稿或放弃 |

## 8. 验收与评估

| ID | 验收标准 |
|---|---|
| HW-AC-01 | 教师只能向有效任课班级发布对应学科作业。 |
| HW-AC-02 | 同一作业可同时包含在线题与拍照提交项。 |
| HW-AC-03 | 缺少评分规则或分值不一致时无法发布。 |
| HW-AC-04 | 主观题不能配置为未经教师确认自动发布成绩。 |
| HW-AC-05 | 学生视角预览与发布后的作业关键信息一致。 |
| HW-AC-06 | 已有提交后修改关键规则会形成版本并说明影响。 |
| HW-AC-07 | AI 不可用时教师仍能完整创建并发布作业。 |
| HW-AC-08 | 多班发布失败时有班级级结果，不出现状态不明。 |

评估指标：创建到发布中位时长、校验阻断分布、草稿放弃率、发布后关键规则修改率。
