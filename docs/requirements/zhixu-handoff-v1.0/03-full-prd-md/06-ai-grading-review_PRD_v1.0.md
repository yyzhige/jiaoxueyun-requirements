## 2. 关键业务规则

1. AI 处理对象是明确 Submission Version，不允许学生重提后静默替换教师正在复核的版本。
2. 每个建议结果包含题目、学生答案、AI 建议分、依据、置信状态、识别来源和模型处理状态。
3. 纯客观题可自动生成建议分；过程题给步骤识别和得分建议；开放题只给评分点命中和评语草稿。
4. 主观题、低置信、识别不完整、评分依据不足和规则冲突必须进入待复核。
5. 教师确认时记录最终分、是否采用 AI、修改原因、公开评语和私密备注。
6. AI 建议分、教师确认分和发布分是不同状态；本模块只产生教师确认分。
7. 更改识别文本后必须重新计算相关建议，旧建议保留版本但不得继续标为有效。
8. 批量接受只适用于满足学校规则的高置信客观题，并展示数量、分值影响和抽检要求。
9. 教师私密备注不向学生展示，也不进入长期 AI 记忆。
10. AI 失败、超时或不可用时自动转人工路径，不阻断整批批改。

## 3. 题型处理矩阵

| 题型 | AI 输出 | 默认复核 | 可批量接受 |
|---|---|---|---|
| 单选、判断、填空标准答案 | 对错、建议分、识别置信 | 低置信 / 规则冲突 | 待确认 |
| 多选 | 选项识别、部分分建议 | 全部规则异常项 | 待确认 |
| 数理过程题 | 步骤、关键点、建议分 | 必须复核 | 否 |
| 作文、开放题、材料题 | 评分点、证据片段、评语草稿 | 必须复核 | 否 |
| 实践 / 背诵 / 活动 | 材料整理、完成状态 | 教师人工确认 | 否 |

| 区域 | 字段 | 规则 |

## 5. 状态矩阵

| 状态 | 含义 | 教师动作 |
|---|---|---|
| 排队中 / 识别中 / 初评中 | 系统处理 | 可离开；允许人工提前进入原始提交 |
| 待复核 | 有建议但需教师判断 | 接受、改分、修正识别、写评语 |
| 无法判断 | 无可靠建议 | 人工批改 |
| 已确认 | 教师已确认当前版本 | 查看、在发布前修正 |
| 版本过期 | 学生已提交新版本 | 切换新版本或保留旧版本说明 |
| 失败 | 系统处理失败 | 重试、人工批改 |

## 6. 需求章节

### 6.1 批改任务概览与队列

- 展示提交数、未交、处理中、待复核、已确认和失败数量。
- 支持按题型、置信、学生、状态和是否迟交筛选。
- 默认优先显示阻断发布的异常、主观题和低置信结果。

### 6.2 逐题复核台

- 左侧原始提交，中间识别 / 学生答案，右侧评分依据与教师决定。
- 教师可用键盘连续处理上一题 / 下一题，但布局尺寸保持稳定。
- 改分时选择原因：识别错误、评分规则不适用、学生答案合理、其他。

### 6.3 识别修正与人工路径

- 修正题目切分或识别文本后，明确标记建议正在重新计算。
- 人工路径允许直接录入分数与评语，不要求等待 AI 重试。
- 整份图片无法识别时可重新切页、重新识别或完全人工批改。

### 6.4 批量确认

- 只显示符合规则的候选数量和题型；主观题永不进入候选。
- 确认前展示总题数、学生数、预计分值影响和抽检样本。
- 批量接受产生教师确认记录，不直接发布。

## 7. 权限与异常

| 场景 | 处理 |
|---|---|
| 任课教师 | 处理本人有效教学任务的学科与班级 |
| 班主任非任课身份 | 只读查看进度，不可改分 |
| 教务 | 可查看进度与汇总；明细改分需额外授权 |
| AI 超时 | 局部转人工，不阻断其他学生 |
| 评分规则被修改 | 当前批次标记规则版本变化，需重新确认受影响结果 |

## 8. 验收与评估

| ID | 验收标准 |
|---|---|
| GRD-AC-01 | 每个 AI 建议包含结论、依据、置信状态和来源。 |
| GRD-AC-02 | 主观题、低置信和识别异常无法绕过教师确认。 |
| GRD-AC-03 | 修正识别后旧建议失效并保留版本记录。 |
| GRD-AC-04 | 教师确认分不自动变成学生可见发布分。 |
| GRD-AC-05 | AI 不可用时可完成人工批改与整批确认。 |
| GRD-AC-06 | 班主任只读身份不能修改他科学科评分。 |
| GRD-AC-07 | 学生重提后教师能识别当前复核版本是否过期。 |
| GRD-AC-08 | 批量接受不包含任何主观题候选。 |

评估指标：教师每题复核时长、AI 建议接受率、识别修正率、人工兜底率、发布前改分率。

- 权威对象：`DAT-GRD-01` 至 `DAT-GRD-04`；原始材料引用 `DAT-SUB-02` 和 `DAT-SUB-03`，评分规则引用 `DAT-HW-03`。
