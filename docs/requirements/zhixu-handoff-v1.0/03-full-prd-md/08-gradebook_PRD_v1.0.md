## 2. 关键业务规则

1. 行为学生，列为作业、测验或考试成绩项；不同成绩类型可筛选但不混用计算规则。
2. 单元格展示当前发布分或业务状态；未发布成绩不得向无权限角色泄露。
3. 缺交、缺考、缓考、免考、无效和未发布使用独立文案与图标，不显示为 0。
4. 任课教师查看所教班级与学科；班主任查看本班全科；教务按授权年级或学校范围查看。
5. 班主任只读查看其他学科成绩，不能从成绩册直接改分。
6. 每个分数可追踪原始提交、教师确认版本、发布版本和修正历史。
7. 列表统计排除免考、无效和未发布；缺交是否计入统计由学校成绩规则决定并显示口径。
8. 导出范围必须显示学校、学期、班级、学科、成绩类型、查询条件和生成时间。
9. 学生端不展示完整班级排名；教师内部排序必须显示范围和参与人数。

## 5. 需求章节

### 5.1 班级成绩矩阵

- 首列学生信息固定；成绩列横向滚动并保持稳定宽度。
- 点击列标题进入成绩项摘要，点击单元格进入本人该成绩详情。
- 空状态区分“尚无成绩项”和“当前筛选无结果”。

### 5.2 筛选与列设置

- 筛选变化后显示当前口径摘要；用户可保存常用视图但不得跨学校共享。
- 支持冻结学生列、选择成绩列显示和调整列顺序；状态列不可被误认为成绩列。

### 5.3 单元格详情

- 展示成绩类型、满分、首次分、当前发布分、状态、发布时间和修正记录。
- 作业成绩提供进入原提交、逐题反馈和订正的入口；具体规则归对应模块。

### 5.4 历史、导入与导出

- 导出前展示范围和敏感数据提示；导出进入 GOV-001 审计。
- 试点导入只用于明确授权的历史成绩或非在线数据，必须先校验和预览。

| 能力 | 任课教师 | 班主任 | 教务 | 学校管理员 |

## 7. 验收与评估

| ID | 验收标准 |
|---|---|
| SCO-AC-01 | 不同成绩类型可筛选且状态口径清楚。 |
| SCO-AC-02 | 缺交、缺考、缓考、免考和无效不显示为 0 分。 |
| SCO-AC-03 | 班主任可看本班全科但不能直接改他科分数。 |
| SCO-AC-04 | 每个分数可追踪确认、发布和修正版本。 |
| SCO-AC-05 | 统计区域显示有效人数和排除规则。 |
| SCO-AC-06 | 导出带完整范围口径并记录审计。 |
| SCO-AC-07 | 学生端不展示完整班级排名。 |

评估指标：教师定位单个成绩耗时、成绩状态误读率、导出口径错误数、版本追踪成功率。

## 数据责任与选择型字段合同

- Gradebook View 是派生视图，不建立独立数据 Owner；成绩单元格继承 `DAT-PUB-02`、`DAT-PUB-03`、`DAT-EXM-03` 或 `DAT-EXM-05` 的 Owner。
- 导出人负责导出文件保管，但不取得源成绩的修改权。
- 选择型字段：`SCO-F001` 至 `SCO-F008`，覆盖学期、年级、班级、学科、成绩类型、时间、状态和显示列。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-007` 发布刷新、`DF-008` 修正刷新、`DF-102` 考试成绩刷新。
- 输入：`DAT-PUB-02/03`、`DAT-EXM-03/05` 当前有效版本；输出：Gradebook View、统计与导出派生结果。
- 本模块不写第二份成绩事实；下游刷新失败显示数据时间和待同步状态，可独立重试。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
