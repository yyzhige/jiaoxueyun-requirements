## 2. 关键业务规则

1. 学校空间内至少存在学年、学期、年级、班级、学科、教师、学生和任课关系。
2. 导入对象分批处理：组织结构、教师、学生、班级成员、任课关系；依赖对象必须先存在或在同批明确创建。
3. 每个成员使用学校内稳定标识匹配；同名不能作为唯一匹配依据。
4. 导入前检查必填、格式、重复、引用不存在、跨学校引用和角色冲突。
5. 更新、创建、停用和无变化必须在确认前分别统计。
6. 转班、休学、毕业、离职和任课变更使用有生效时间的状态变更，不删除历史关系。
7. 任课关系变化后，重新计算教师的数据权限；不得把历史教学内容改归新教师。
8. 导入采用批次，支持失败明细和安全重试；不能因重复重试产生重复成员。
9. 敏感字段仅用于必要激活或学校管理，不出现在普通教师学生列表。
10. 所有导入、停用和关系变更进入 GOV-001 审计。

## 5. 需求章节

### 5.1 组织总览

- 展示当前学期、年级、班级、教师、学生和未完整任课关系数量。
- 识别缺班主任、缺任课教师、无班级学生和重复学号等待处理项。

### 5.2 导入与字段映射

- 提供对象对应模板；上传后自动识别列名并允许人工映射。
- 映射页显示样例值、目标字段、是否必填和错误提示。
- 未映射必填字段不能进入校验。

### 5.3 校验与影响预览

- 按创建、更新、停用、无变化和错误分组。
- 对转班、离职和任课变更显示对作业、成绩、计划和权限的影响摘要。
- 用户确认的是具体批次快照；源文件变更后必须重新校验。

### 5.4 导入结果

- 展示批次级与行级结果；失败项可导出并修正重试。
- 导入完成后刷新 ACC-001 身份、教师班级权限和相关选择器。

## 6. 权限与异常

| 能力 | 学校管理员 | 教务 | 普通教师 |
|---|---|---|---|
| 维护学校组织 | 是 | 授权范围 | 否 |
| 导入教师 / 学生 | 是 | 授权范围 | 否 |
| 授予管理员角色 | 已授权管理员 | 否 | 否 |
| 查看导入敏感字段 | 最小必要 | 最小必要 | 否 |

异常：文件过大分批校验；重复重试保持幂等业务结果；跨学校标识直接阻断；部分成功不得隐藏失败项。

## 7. 验收与评估

| ID | 验收标准 |
|---|---|
| ORG-AC-01 | 导入前完成字段映射、校验和影响预览。 |
| ORG-AC-02 | 同名成员不会仅凭姓名合并。 |
| ORG-AC-03 | 转班、离职和任课变更保留历史有效期。 |
| ORG-AC-04 | 任课变更后新权限生效，历史内容归属不被改写。 |
| ORG-AC-05 | 重试失败项不会创建重复成员或关系。 |
| ORG-AC-06 | 部分成功提供行级结果和可修正错误明细。 |
| ORG-AC-07 | 导入与角色变更进入审计。 |

评估指标：首次导入通过率、错误类型分布、重复对象率、权限刷新延迟、导入支持工单数。

## 数据责任与选择型字段合同

- 权威对象：`DAT-ORG-01` 至 `DAT-ORG-11`，账号与身份同时引用 `DAT-ACC-02`、`DAT-ACC-03`。
- Owner 边界：学校管理员负责成员与授权治理，教务负责学期、班级、课程和任课等教学组织数据；导入操作者不自动成为被导入数据 Owner。
- 选择型字段：`ORG-F001` 至 `ORG-F011`，覆盖学期、年级、班级、教师、组织、任课关系、导入类型、映射、处理动作和校验结果。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-002` 组织导入与权限刷新，任课 / 身份变化继续进入 `DF-013`，上下文进入 `DF-015`。
- 输入：`DAT-ORG-11`、字段映射和当前主数据版本；输出：`DAT-ORG-01~10`、`DAT-ACC-02/03` 新版本及对象级结果。
- 批次允许对象级部分成功；已成功对象不重复写入，错误停用通过反向新版本恢复。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
