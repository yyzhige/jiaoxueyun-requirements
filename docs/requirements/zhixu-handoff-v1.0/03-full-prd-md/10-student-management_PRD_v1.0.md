## 2. 业务目标与边界

教师需要从班级或学科视角快速定位学生近期作业、成绩、订正和计划状态，并留下可控范围的跟进记录。页面不承担完整学籍管理，不展示与教学无关的敏感个人信息。

## 3. 关键业务规则

1. 学生目录绑定当前学校、学期、身份和有效教学关系。
2. 任课教师只查看所教学科相关的成绩、作业、错题和计划；班主任查看本班全学科摘要。
3. 班主任不能修改其他任课教师的评分、知识点判断或学科计划内容。
4. 学生详情以学习对象为中心，行政信息只展示完成教学所需的最小字段。
5. 关注事件由可验证事实触发，例如连续缺交、订正未通过、任务堆积、成绩波动和学生主动反馈困难。
6. 事件可以关闭、恢复或标记已处理，不产生永久学生标签。
7. 跟进记录必须选择可见范围；私密记录不进入 AI 长期记忆，也不出现在家长报告。
8. 跨学期查看默认只读，不能用当前任课关系自动获得历史学期全部明细。
9. 学生转班后历史记录保留原班级上下文，新任务进入新班级。

## 4. 字段表

| 区域 | 字段 | 可见规则 |
|---|---|---|
| 学生行 | 姓名、学号后四位、班级、当前状态、近期任务摘要 | 按身份范围 |
| 学习摘要 | 作业完成、成绩趋势、订正、计划进度、关注事件 | 任课教师限本学科，班主任全科 |
| 详情概览 | 基本教学信息、今日任务、近期反馈、计划摘要 | 最小必要 |
| 跟进记录 | 类型、正文、可见范围、创建人、时间、关联对象 | 受记录权限限制 |
| 联系信息 | 学校配置允许的监护沟通入口 | 试点默认不展示完整联系方式 |

## 5. 状态与筛选

| 状态 / 事件 | 触发示例 | 处理 |
|---|---|---|
| 正常 | 无待处理事件 | 不额外标记 |
| 连续缺交 | 连续 N 次已发布作业缺交 | 生成可关闭事件 |
| 订正未通过 | 多次订正仍未达到规则 | 进入跟进与计划候选 |
| 多学科任务堆积 | 未来任务量超学校阈值 | 班主任协调 |
| 计划未完成 | 到期任务未完成 | 任课教师 / 班主任查看 |
| 学生主动反馈 | 不会做、任务过多、设备问题 | 展示原始反馈和处理状态 |

筛选支持班级、学科、作业状态、计划状态、关注事件和关键词；筛选结果不能扩大当前身份数据范围。

## 6. 需求章节

### 6.1 学生目录

- 任课教师默认进入当前学科班级列表；班主任默认进入本班全体学生。
- 每行只展示高信息密度摘要，不在列表堆叠完整成绩和标签。
- 点击学生进入详情并保留返回列表时的筛选、排序和滚动位置。

### 6.2 学生详情概览

- 顶部显示学生、班级、学期和当前查看身份范围。
- Tabs：概览、作业与反馈、成绩、错题与证据、提升计划、跟进记录。
- 任课教师看不到其他学科明细；班主任可以切换学科但他科内容只读。

### 6.3 学科与全科视图

- 学科视图由对应任课教师负责；全科视图显示任务总量、各学科状态和跨学科冲突。
- 不使用单一总分给学生贴能力标签；展示时间范围和证据来源。

### 6.4 跟进记录

- 支持学习沟通、作业跟进、计划协调和学生反馈四类记录。
- 可见范围候选：仅本人、本学科教师、本班教师；具体默认值待确认。
- 删除采用更正 / 撤回语义并保留审计，不做物理删除。

| ID | 验收标准 |

## 数据责任与选择型字段合同

- `DAT-STU-01` 学生学习档案是聚合视图，字段继承组织、成绩、学情和计划源对象 Owner；`DAT-STU-02` 跟进记录由每条记录的创建角色负责。
- 班主任拥有全科协调记录，不拥有跨学科成绩、掌握判断和计划内容。
- 选择型字段：`STU-F001` 至 `STU-F007`，覆盖班级、学科、作业状态、关注事件、计划状态、跟进类型和可见范围。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-007`、`DF-008`、`DF-010`、`DF-011`、`DF-012`、`DF-013` 和 `DF-102`。
- 输入：组织、成绩、学情、计划和跟进源版本；输出：Student Learning Profile 聚合刷新与 `DAT-STU-02` 跟进记录。
- 聚合刷新不产生第二份学籍、成绩或计划事实；跟进记录按创建角色和可见范围独立版本化。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
