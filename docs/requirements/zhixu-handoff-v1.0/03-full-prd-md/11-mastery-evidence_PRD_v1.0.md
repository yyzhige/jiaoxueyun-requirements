## 2. 关键业务规则

1. 证据来源包括首次作答、题目难度、错误类型、教师确认分、订正和后续同类表现。
2. 单一题目或一次作业只能增加证据，不能直接形成“已掌握”或“明显薄弱”的强结论。
3. 状态固定为：数据不足、初步掌握、基本掌握、熟练掌握、需要巩固、明显薄弱。
4. 每个状态必须能展开查看形成该判断的证据和时间范围。
5. 证据相互冲突或样本过少时优先显示数据不足或不稳定，不强行归类。
6. 教师可修正题目知识点归属和掌握状态，必须填写原因并保留原判断。
7. 任课教师负责本学科；班主任查看本班全科摘要但不能修改他科状态。
8. 学生看到通俗解释、近期证据和下一步行动，不显示模型置信、内部权重或同学对比。
9. 掌握状态用于生成提升计划候选，不自动使计划生效。

## 3. 字段与状态

| 对象 | 字段 |
|---|---|
| Mastery Evidence | 学生、学科、知识点、来源对象、首次 / 订正、结果、难度、错误类型、时间 |
| Mastery State | 当前状态、证据数、时间范围、最近变化、系统说明、教师修正标记 |
| Mastery Override | 原状态、新状态、原因、教师、时间、有效范围 |

| 数据条件 | 状态行为 |
|---|---|
| 无证据或证据过少 | 数据不足 |
| 多次正确且跨时间稳定 | 基本 / 熟练掌握候选 |
| 首次错误、订正通过 | 初步掌握或需要巩固，不能直接熟练 |
| 多次同类错误且订正未通过 | 明显薄弱候选 |
| 证据冲突 | 显示不稳定说明并保留证据 |

具体阈值由后续学科规则与技术评估确定，不在产品 PRD 伪造统一数值。

## 4. 需求章节

### 4.1 班级学情

- 按知识点展示状态分布、有效证据人数和数据不足人数。
- 点击状态分布进入学生列表，保留学科、知识点和时间范围。
- 不以单一红绿热力图代替状态文字和证据数量。

### 4.2 学生知识点视图

- 展示知识点、当前状态、证据数量、最近变化和是否进入提升计划。
- 支持按章节、状态和时间筛选；历史状态变化可追踪。

### 4.3 证据详情与修正

- 时间线展示首次作答、教师复核、订正和后续表现。
- 教师修正后，系统后续只可提出“建议重新评估”，不能静默覆盖人工判断。
- 修正知识点归属时同步提示会影响哪些学情与计划候选。

### 4.4 学生可见摘要

- 文案示例：“你在一元一次方程移项上还需要巩固，最近 3 次相关作答中有 2 次在符号变化处出错。”
- 提供查看相关错题、开始订正或查看提升任务入口。

## 5. 权限与异常

| 场景 | 处理 |
|---|---|
| 题目未绑定知识点 | 进入待归类，不参与强结论 |
| 证据来源被修正 | 重新计算候选状态并保留历史 |
| 任课关系失效 | 教师失去新增 / 修正权限，历史操作保留 |
| 学生跨班 | 证据跟随学生，班级汇总按时间范围计算 |

## 6. 验收与评估

| ID | 验收标准 |
|---|---|
| INS-AC-01 | 单道题不能直接形成确定掌握结论。 |
| INS-AC-02 | 每个状态可展开查看证据、时间和来源。 |
| INS-AC-03 | 数据不足或证据冲突时不生成伪精确强结论。 |
| INS-AC-04 | 教师修正知识点或状态需要原因并保留历史。 |
| INS-AC-05 | 班主任不能修改他科学情判断。 |
| INS-AC-06 | 学生端不展示内部权重、模型置信和同学对比。 |
| INS-AC-07 | 状态变化不会自动使提升计划生效。 |

评估指标：数据不足占比、教师修正率、证据可解释性通过率、状态与教师判断一致率。

## 数据责任与选择型字段合同

- 权威对象：`DAT-INS-01` 掌握证据、`DAT-INS-02` 掌握状态、`DAT-INS-03` 人工修正。
- Owner 边界：对应任课教师对知识点归属和正式掌握判断负责；AI 只计算候选与说明。
- 选择型字段：`INS-F001` 至 `INS-F011`，覆盖学期、章节、状态、学生、知识点、证据阶段、结果、难度、错误类型和修正。
