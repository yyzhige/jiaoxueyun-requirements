## 2. 关键业务规则

1. Exam Event 绑定学校、学期、年级、考试类型和参与范围。
2. 每科成绩定义满分、计分方式、缺考 / 缓考 / 免考规则和负责教师。
3. 导入必须先完成字段映射、学生匹配、分数范围、重复记录和状态校验。
4. 成绩审核完成前不向学生发布，不进入综合成绩。
5. 综合成绩引用已发布成绩版本和明确权重规则；规则修改产生新版本，不回写历史结果。
6. 缺考、缓考、免考和无效成绩不能用 0 分替代。
7. 排名如启用，必须显示范围、参与人数、同分处理和时间；学生端默认不展示完整排名。
8. 成绩修正沿用 PUB-001 版本和审计原则。

| 对象 | 核心字段 |

| 状态 | 流转 |

## 4. 需求章节

### 4.1 考试设置

- 配置年级、班级、科目、时间和负责教师；缺少负责教师或满分时不能进入收集。
- 同一学生跨班或转班时按考试时点快照确定参与范围。

### 4.2 成绩录入与导入

- 支持模板导入与授权教师手工录入；每次操作形成批次。
- 错误按学生行展示，不因少数错误静默跳过；是否允许部分成功待学校规则确认。

### 4.3 审核与发布

- 教务查看各科完成度和异常；学科教师确认本学科。
- 发布前展示参与人数、有效成绩数、异常状态和统计口径。

### 4.4 综合成绩

- 支持引用作业、测验和考试成绩，但每个组成项必须显示来源版本。
- 结果可展开查看原始成绩、权重、舍入和规则版本。

## 5. 验收候选

| ID | 验收标准 |
|---|---|
| EXM-AC-01 | 导入前能识别学生不匹配、重复、超分和非法状态。 |
| EXM-AC-02 | 未审核考试成绩不向学生发布。 |
| EXM-AC-03 | 缺考、缓考、免考和无效使用独立状态。 |
| EXM-AC-04 | 综合结果可追踪原始分、权重和规则版本。 |
| EXM-AC-05 | 修改综合规则不重写历史已发布结果。 |
| EXM-AC-06 | 学生端默认不展示完整班级排名。 |

## 6. 开放决策

考试类型、等级制、部分导入、补考替代、排名、权重、同分和舍入规则必须由试点学校确认。

## 数据责任与选择型字段合同

- 权威对象：`DAT-EXM-01` 至 `DAT-EXM-05`，覆盖考试事件、科目配置、学科成绩、导入批次和综合规则。
- Owner 边界：教务负责考试口径、范围和综合规则；对应任课教师负责本学科原始成绩。
- 选择型字段：`EXM-F001` 至 `EXM-F013`；学校未确认的考试细则通过学校配置表达，不虚构统一值。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-102` 考试成绩到发布、成绩册与学情。
- 输入：`DAT-EXM-01/02/04` 和教师确认的 `DAT-EXM-03`，可选 `DAT-EXM-05`；输出：发布版本与 SCO / INS / STU 刷新。
- 科目级部分失败不发布无效科目；综合规则变化只影响规定生效点后的结果，不追溯改写历史。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
