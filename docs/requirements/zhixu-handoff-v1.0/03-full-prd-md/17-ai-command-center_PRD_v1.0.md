## 2. 能力等级

| 等级 | 示例 | 处理 |
|---|---|---|
| 查询 | “找出七一班本周缺交两次以上的学生” | 权限校验后直接返回 |
| 分析 | “总结这次作业最常见的三个错误” | 返回范围、证据和局限 |
| 生成草稿 | “生成一份周末数学作业” | 保存草稿，进入 HW-001 |

## 3. 关键业务规则

1. AI 只可使用当前用户在当前学校、身份、学期和数据范围内可访问的信息。
2. 每次对话显示当前工作上下文；引用“刚才的作业”等对象时展示实际对象名称与 ID 摘要。
3. 缺少班级、学科、时间范围或目标对象时先追问，不自行扩大范围。
4. 查询结果显示数据范围、生成时间、证据来源和无数据 / 数据不足说明。
5. 生成内容进入对应业务模块的草稿，不在对话内建立第二套业务状态。
6. 操作预览必须展示对象、数量、关键参数、权限、可逆性和通知影响。
7. 用户确认时重新校验权限和对象版本；上下文已变化则阻断并要求重新预览。
8. 每次执行记录原指令、解析参数、执行人、学校、身份、对象、结果和错误。
9. API Key、未发布成绩、教师私密备注和学生敏感信息不得进入授权记忆。
10. 授权记忆仅保存用户主动确认的格式 / 偏好，可查看、修改、删除和到期。
11. 学生助手不能代替学生提交作业、自动完成答案、修改成绩或查看他人数据。

## 4. 上下文模型

| 层级 | 内容 | 生命周期 |
|---|---|---|
| 会话上下文 | 当前目标、筛选、引用对象、草稿 | 当前会话 |
| 工作上下文 | 学校、身份、学期、页面、班级、学科 | 随业务切换 |
| 授权记忆 | 评分标准偏好、作业格式、文案偏好 | 用户可控、学校可配置保留期 |

## 5. 状态矩阵

| 状态 | 行为 |
|---|---|
| 理解中 | 显示正在理解，不执行业务动作 |
| 待澄清 | 提出一个最关键问题 |
| 查询完成 | 展示结果与范围 |
| 草稿已生成 | 提供进入业务模块编辑入口 |
| 待确认 | 展示结构化影响预览 |
| 执行中 | 可离开，任务中心保留进度 |
| 成功 / 部分成功 / 失败 | 展示对象级结果和下一步 |
| 上下文失效 | 旧会话只读，不允许继续执行 |

## 6. 需求章节

### 6.1 命令栏与对话

- Web 命令栏支持快速输入；复杂任务展开右侧对话面板。
- 面板不遮挡当前关键表格操作区；可收起并保留会话。
- 对话中所有业务对象提供进入实际模块的链接。

### 6.2 查询与分析

- 结果卡包含结论、范围、数据时间、证据和可继续追问的对象。
- 对排名、风险学生等敏感结果必须显示口径，不自动对学生贴标签。

### 6.3 草稿与操作预览

- 作业、评语和提升计划进入对应模块草稿。
- 发布成绩、批量通知和调课必须进入待确认任务中心，不能只靠聊天中的“好”。
- 确认按钮写出实际动作和影响数量。

### 6.4 学生学习助手

- 可解释本人已发布反馈、提示学习步骤、帮助规划今日任务和提交困难反馈。
- 教师要求独立完成的题目遵守 APP-002 提示策略。
- 不生成可直接替代作答的完整答案，除非教师规则已开放解析。

## 7. 权限与异常

| 场景 | 处理 |
|---|---|
| 无权限 | 拒绝并说明可理解的权限范围，不泄露对象是否存在 |
| 对象已变化 | 预览失效，重新加载后确认 |
| 执行部分失败 | 返回对象级成功 / 失败，不重复执行成功项 |
| 模型不可用 | 业务页面仍可手工使用；保留草稿和重试 |
| 切换学校 / 身份 | 旧会话变只读，新建当前上下文会话 |

## 8. 验收与评估

| ID | 验收标准 |
|---|---|
| AI-AC-01 | 查询结果不超出当前学校、身份和数据范围。 |
| AI-AC-02 | 缺失关键参数时先追问，不自行扩大范围。 |
| AI-AC-03 | 生成内容进入实际业务模块草稿。 |
| AI-AC-04 | 高风险操作展示结构化预览并重新校验权限。 |
| AI-AC-05 | 切换学校或身份后旧会话不能继续执行。 |
| AI-AC-06 | 每次执行包含完整审计信息。 |
| AI-AC-07 | 授权记忆可查看、修改、删除且不保存敏感字段。 |
| AI-AC-08 | 学生助手不能替学生提交或查看他人数据。 |

评估指标：一次理解成功率、澄清轮次、草稿采用率、预览取消率、误操作数、越权拦截数。

## 数据责任与选择型字段合同

- 权威对象：`DAT-AI-01` 会话、`DAT-AI-02` 授权记忆、`DAT-AI-03` 业务草稿 / 确认任务、`DAT-AI-04` 执行记录。
- Owner 边界：AI 不拥有成绩、计划、权限、课表或作业；`DAT-AI-03` 始终继承对应业务对象 Owner。
- 选择型字段：`AI-F001` 至 `AI-F007`，覆盖工作上下文、澄清范围、能力等级、任务状态和确认范围。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-014` 查询 / 草稿 / 预览 / 执行，`DF-015` 上下文失效，`DF-016` 审计；自动化引用 `DF-301`。
- 输入：`DAT-ACC-04`、`DAT-AI-01`、目标 Data ID / 版本和用户指令；输出：查询结果、业务草稿、`DAT-AI-03/04`。
- AI 不建立第二套业务事实；预览基于目标版本，目标或权限变化后原确认任务失效。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
