## 2. 业务目标与边界

让学生明确知道要完成什么、完成到哪里、提交是否成功以及下一步是什么；在网络和拍照质量不稳定时仍能继续，而不是丢失答案或进入状态不明。

本模块不展示 OCR、模型队列和内部错误术语；不允许学生在提交阶段看到未发布答案或评分。

## 3. 关键业务规则

1. 学生只能访问本人、当前学校、当前学期且已发布的作业。
2. 开始作答前展示提交方式、截止、补交、重提、预计用时和反馈开放规则。
3. 在线答案按题本地暂存并在联网后同步；服务端版本确认后才显示“已保存”。
4. 拍照页必须支持裁边、旋转、多页排序、删除和补拍。
5. 图片质检至少检查模糊、过暗、缺页和明显重复；低置信建议允许学生选择仍然提交。
6. 最终提交前展示在线题完成度、拍照页数、漏答、迟交状态和提交后规则。
7. 提交成功必须产生服务端 Submission Version、提交时间和可查询状态。
8. 客户端超时不能直接判定失败；应查询服务端是否已经生成版本。
9. 迟交、补交和重提均保留原版本，不覆盖历史提交。
10. 已截止且学校不允许补交时，学生仍可查看任务说明和本人历史提交，但不能新增版本。

## 5. 状态矩阵

| 状态 | 学生可见文案 | 可执行操作 |
|---|---|---|
| 未开始 | 未开始 | 开始作业 |
| 进行中 | 已保存至具体时间 / 待同步 | 继续、拍照、提交 |
| 上传中 | 正在上传 X/Y | 离开后后台继续、重试失败页 |
| 待确认 | 提交前检查 | 返回修改、确认提交 |
| 已提交 | 已提交，等待老师批改 | 查看提交摘要 |
| 需补充 | 老师要求补充 | 查看原因、提交新版本 |
| 已退回 | 需要重新提交 | 查看原因、重新作答 |
| 已截止 | 已截止 | 按规则补交或只读 |

## 6. 需求章节

### 6.1 作业详情

- 首屏展示截止、预计用时、完成进度和主要行动按钮。
- 混合作业分别显示在线题和拍照部分完成度。
- 教师说明过长时折叠，但截止、提交规则和页数要求不得折叠。

### 6.2 在线答题

- 支持上一题 / 下一题、题号导航、标记稍后检查和剩余题数。
- 网络断开时继续编辑，并明确显示“仅保存在本机”；恢复后自动同步。
- 另一设备打开时提示最近服务端版本，避免静默覆盖。

### 6.3 拍照提交

- 相机拍摄后进入裁边确认；允许从相册选择。
- 每页显示上传进度与质检建议；失败只影响当前页。
- 缺页检查基于作业要求页数；自由页数作业不误报缺页。

### 6.4 提交确认与结果

- 提交前列出漏答题与未上传页；学生可以返回补充或确认按当前内容提交。
- 确认后按钮进入防重复状态；超时后查询实际提交结果。
- 成功页显示版本、时间、迟交状态和“等待老师批改”，不显示 AI 处理中。

## 7. 异常处理

| 异常 | 产品行为 |
|---|---|
| 图片模糊 | 标记具体页，允许重拍或仍提交 |
| 上传中断 | 保留本地文件与已上传页，支持继续 |
| 重复页 | 提示疑似重复，不自动删除 |
| 截止时仍上传 | 按服务端提交时间与补交规则判定，不按本机时间 |
| 客户端崩溃 | 重新进入恢复本地草稿与服务端同步状态 |
| 作业被教师撤回 | 停止新提交，保留学生已完成内容并说明原因 |

## 8. 验收与评估

| ID | 验收标准 |
|---|---|
| SUB-AC-01 | 在线答案在断网、退出和重新进入后可恢复。 |
| SUB-AC-02 | 拍照支持多页排序、裁边、旋转、删除和补拍。 |
| SUB-AC-03 | 低置信图片质检不造成不可解释的强制阻断。 |
| SUB-AC-04 | 最终提交前展示漏答、页数、迟交和重提规则。 |
| SUB-AC-05 | 网络超时重试不会产生用户不可见的重复版本。 |
| SUB-AC-06 | 提交成功显示服务端时间和版本，状态可再次查询。 |
| SUB-AC-07 | 学生无法查看其他学生提交或未发布评分信息。 |
| SUB-AC-08 | AI 或批改服务不可用不影响学生提交。 |

评估指标：无需重拍即可提交比例、提交失败率、断网恢复成功率、状态不明工单数、平均提交耗时。

## 数据责任与选择型字段合同

- 权威对象：`DAT-SUB-01` 作答草稿、`DAT-SUB-02` 提交媒体、`DAT-SUB-03` 提交版本。
- Owner 边界：学生对本人原始作答和提交负责；教师与 AI 不得代答，识别结果不得覆盖原图。
- 选择型字段：`SUB-F001` 至 `SUB-F005`，覆盖提交方式、图片来源、质检、同步状态和提交版本选择。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-004` 学生草稿到不可变提交版本；成功后触发 `DF-005`。
- 输入：`DAT-HW-05`、`DAT-SUB-01/02`；输出：新 `DAT-SUB-03`、旧版本替代标记和任务状态刷新。
- 上传未完成不产生有效提交；重复请求返回同一版本；重提使旧批改标记版本过期而非静默替换。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
