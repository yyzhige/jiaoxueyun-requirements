## 2. 关键业务规则

1. CLI 登录后必须选择或明确当前学校和身份；无上下文命令不得默认使用最近学校执行修改。
2. 自然语言与结构化命令调用 AI-001 和业务模块的同一能力，不复制业务规则。
3. 查询类命令可直接输出有权限结果，并显示范围、时间和分页 / 截断说明。
4. 生成类命令只保存草稿，并返回实际业务对象链接或标识。
5. 修改类命令默认 `preview`，展示对象数量、关键变化、可逆性和通知影响。
6. 高风险操作必须交互确认；非交互自动化需要单独授权、明确范围、有效期和最大影响量。
7. 无权限命令拒绝且不泄露敏感对象；切换学校后连续会话引用失效。
8. 所有输入、解析、预览、确认、执行和结果进入 GOV-001 审计；敏感值在终端输出中脱敏。
9. CLI 输出支持人类可读与结构化模式，但产品含义一致。

## 5. 需求章节

### 5.1 一句话命令与连续会话

- 示例：“在石家庄明德实验中学，以教务身份检查七年级三个班的任课关系缺口。”
- 后续“把缺口导出”继承已明确范围，但执行前仍显示实际范围。
- 会话引用显示实际对象，不依赖隐藏的“它 / 刚才那些”执行高风险动作。

### 5.2 预览与自动化

- 修改命令先输出 preview token 或等价任务引用；对象变化后原预览失效。
- 自动化授权限制命令域、学校、数据范围、操作类型、有效期和最大影响量。
- 自动化不允许默认发布成绩、修改权限或发布课表。

## 6. 验收候选

| ID | 验收标准 |
|---|---|
| CLI-AC-01 | 修改命令无明确学校与身份时不能执行。 |
| CLI-AC-02 | 查询、草稿和修改权限与 Web / AI 指令中心一致。 |
| CLI-AC-03 | 修改默认先预览，目标变化后旧预览失效。 |
| CLI-AC-04 | 高风险操作不能靠普通非交互参数跳过确认。 |
| CLI-AC-05 | 自动化授权有范围、有效期和最大影响量。 |
| CLI-AC-06 | 终端输出不泄露未授权或未脱敏的学生敏感数据。 |
| CLI-AC-07 | 所有执行进入统一审计。 |

## 7. 开放决策

目标用户、发行方式、认证、结构化输出、首批命令域、自动化审批和学校集成方式需在区域 / 私有化阶段专题确认。

## 数据责任与选择型字段合同

- 权威对象：`DAT-CLI-01` CLI 会话上下文、`DAT-CLI-02` 自动化授权；查询和操作结果继承对应业务模块 Data ID。
- Owner 边界：CLI 只是入口，不建立独立业务规则，也不转移作业、成绩、计划、课表和审计 Owner。
- 选择型字段：`CLI-F001` 至 `CLI-F006`，覆盖上下文、输出模式、命令域、确认、自动化范围和有效期。
- 中央事实源：[数据 Owner 矩阵](../07-structured-requirements/data-ownership-matrix.md)；[字段与选项字典](../07-structured-requirements/field-option-catalog.md)。

## 数据流转合同

- 参与 Flow：`DF-014` CLI 查询 / 草稿 / 预览 / 执行，`DF-015` 上下文失效，`DF-016` 审计，`DF-301` 自动化授权生命周期。
- 输入：`DAT-CLI-01/02`、当前上下文、目标 Data ID / 版本和命令；输出：目标业务模块版本、执行结果和审计。
- CLI 复用目标模块 Flow；过期、超范围或超过最大影响量时失败关闭，部分成功只重试失败对象。
- 中央事实源：[跨模块数据流转合同](../07-structured-requirements/data-flow-catalog.md)。
