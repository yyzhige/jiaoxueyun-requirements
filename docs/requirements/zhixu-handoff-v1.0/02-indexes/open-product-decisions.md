# 开放产品决策

这些问题会改变用户体验、责任边界或试点范围，需要产品确认；技术实现问题不放在本表。

| 决策 ID | 模块 | 问题 | 建议默认值 | 不确认的影响 |
|---|---|---|---|---|
| PD-001 | ACC-001 | 学生首次激活使用什么凭据 | 学号 + 学校发放初始口令 | 登录 / 激活流程无法定稿 |
| PD-002 | TEA-001 | 多身份用户是否分别记忆首页 | 按学校 + 身份分别记忆 | 工作台默认体验不确定 |
| PD-003 | HW-001 / SUB-001 | 截止前是否允许学生主动撤回重提 | 允许重提但保留版本 | 提交与批改版本规则不完整 |
| PD-004 | GRD-001 | 高置信客观题能否批量接受 | 允许，但需抽检且只生成教师确认分 | 批改效率目标无法验证 |
| PD-005 | PUB-001 | 成绩按整班还是按学生分批发布 | 试点默认整班；异常学生可排除并明确提示 | 发布状态和通知规则不完整 |
| PD-006 | SCO-001 | 是否允许手工新增非作业成绩列 | 试点不允许，走导入或后续考试模块 | 成绩册边界不清 |
| PD-007 | STU-001 | 跟进记录默认可见范围 | 仅本人，创建时可扩大到本学科 / 本班教师 | 教师隐私和协作边界不清 |
| PD-008 | INS-001 | 人工修正掌握状态的有效期 | 保持有效，后续只提出重新评估建议 | 人工判断可能被系统静默覆盖 |
| PD-009 | PLN-001 | 同时目标、每日时长和计划周期 | 同时重点目标不超过 3 个；每日提升任务建议不超过 30 分钟；周期 7-14 天 | 任务负担无法校验 |
| PD-010 | APP-001 | 学生能否调整任务优先级 | 可调整同优先级建议任务，不可降低正式截止任务 | 首页排序行为不确定 |
| PD-011 | APP-002 | 订正自动判定边界 | 标准客观题可建议通过；主观题与低置信必须教师复核 | 订正闭环责任不清 |
| PD-012 | ORG-001 | 试点学校现有数据模板和激活字段 | 以学校真实模板为准，先做映射评审 | 组织导入无法进入原型验证 |
| PD-013 | AI-001 | 学生助手首轮允许哪些能力 | 解释已发布反馈、分层提示、规划任务、反馈困难；不代答 | 学生 AI 边界不清 |
| PD-014 | GOV-001 | 哪些教务岗位可临时查看学生明细 | 仅明确岗位申请，限范围限时审批 | 权限模型无法评审 |
| PD-015 | PREP-001 | 备课授课首个版本的最小载体 | 先备课编辑 + 课堂任务发起，不含硬件与录制 | P1 范围不清 |
| PD-016 | EXM-001 | 考试、等级、排名和权重规则 | 等待试点学校真实规则 | 综合成绩不可进入详细设计 |
| PD-017 | SCH-001 | 排课硬软约束和节次规则 | 等待试点学校课表样本 | 排课只能保持概念边界 |
| PD-018 | CLI-001 | CLI 首批用户和命令域 | 后期先面向学校管理员 / 集成方做查询与预览 | CLI 不进入近期范围 |

## 评审顺序

先确认 PD-001、PD-003、PD-004、PD-005、PD-007、PD-009、PD-011、PD-013、PD-014；这些会直接影响 P0 原型和教学闭环。P1-P3 决策可保持开放，但必须继续标记为后续版本。
