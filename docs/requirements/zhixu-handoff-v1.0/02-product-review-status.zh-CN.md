## 产品确认前必须关闭

1. 产品负责人逐模块确认 P0 范围、非范围和开放决策。
2. 确认首轮原型覆盖哪些 Prototype ID，以及哪些只保留线框。
3. 确认学生数据、作业图片和第三方 AI 传输的产品合规边界。
4. 确认试点学科与题型组合，以及每类题的人工复核规则。
5. 确认备课授课、综合成绩、排课和 CLI 继续留在后续版本。
6. 确认 P0 权威对象的最终 Owner、Steward 和正式确认人。
7. 确认学校主数据选项、固定枚举、级联关系、默认值和停用历史展示规则。
8. 确认 P0 Flow 的输入输出版本、人工门禁、对象级部分成功、补偿和下游失效规则。

## 禁止误读

- `产品评审稿` 不等于 PM 已批准。
- 线框存在不等于高保真设计完成。
- 产品对象完整不等于 API 或数据库已经确定。
- AI 能力描述不授权模型自动发布成绩、计划、通知或课表。
- Data ID 与 Field ID 已登记不等于学校已经确认对应 Owner 和选项值。
- Flow ID 已登记不等于技术接口、数据库或消息机制已经确定。
