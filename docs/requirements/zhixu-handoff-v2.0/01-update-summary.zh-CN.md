# v2.0 重构摘要

## 1. 重构性质

本次是建立新基线和完整需求包，不覆盖 v1.0 历史评审稿。

## 2. 关键修正

- 产品端统一为 Web 和 App，所有角色均可进入两端。
- App 不要求完整复制 Web，端能力差异进入 Capability Matrix。
- 终端命令行从产品形态中移除，改为 Web/App 内 AI 对话与一句话任务执行。
- AI 报表按临时、定期、长期三种时间形态定义。
- 长期学习路径中的解释性结论由对应任课教师确认后才对学生展示。
- 学生每个学科提升点同步给对应任课教师，班主任拥有本班全科查看和协调权限。
- 第三方通知、AI 讲题视频、AI 教学视频只作为第二阶段扩展登记。
