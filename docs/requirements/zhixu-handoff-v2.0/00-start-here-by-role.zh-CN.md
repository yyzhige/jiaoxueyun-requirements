# 按角色开始阅读

| 角色 | 先读 | 重点检查 |
| --- | --- | --- |
| PM | 产品总基线、开放决策、模块 PRD | 范围是否与石家庄公办初中试点一致；第二阶段内容是否越界 |
| 前端 | 线框合同、字段字典、端能力矩阵 | Web/App 差异是否被明确登记；选择型字段是否有 Option Set |
| 后端 | 数据对象、Owner、状态、Flow、权限矩阵 | 每个写入是否有源版本、目标版本、幂等、补偿和审计 |
| QA | 验收标准、状态机、异常合同、扫描报告 | 是否能按模块和 Flow 生成测试用例 |
| 设计 | 线框合同、产品基线、角色模型 | App 不复制 Web，Web 保留完整业务效率 |
| 数据/安全 | 数据治理、审计、AI 使用合同 | 未成年人数据、导出、敏感访问和 AI 传输边界 |
