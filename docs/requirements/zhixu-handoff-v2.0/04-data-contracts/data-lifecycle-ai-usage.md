# 数据生命周期、隐私与 AI 使用规则

## 1. 生命周期原则

1. 学校是数据控制与治理主体，平台是按授权处理者。
2. 学生可以是本人作答的产生者和数据主体，但不承担学校数据保留、归档和删除责任。
3. 正式业务事实采用版本化修正，不通过物理删除掩盖历史。
4. 历史学期默认只读，除合规修正外不允许新增教学事实。
5. 导出、敏感访问、AI 执行、授权变更必须进入审计。

## 2. AI 数据使用边界

1. AI 可以是识别、建议、草稿、解释候选和报表的产生者。
2. AI 不能成为正式成绩、学情、计划、权限和治理策略的业务 Owner。
3. AI 查询必须绑定当前学校、身份、学期、权限和数据范围。
4. AI 分析必须展示来源、时间范围、置信限制和不可解释部分。
5. 解释性结论进入学生可见路径前必须经对应任课教师确认。
6. 第一阶段不向第三方渠道发送学生明细。

## 3. 敏感级别

| 级别 | 数据 | 处理要求 |
| --- | --- | --- |
| S1 | 学校配置、课程目录、公开模板 | 按角色授权 |
| S2 | 作业、成绩册视图、报告摘要 | 按学校、班级、学科、身份过滤 |
| S3 | 学生作答图片、成绩、证据、计划、学习路径 | 最小必要展示，导出审批，AI 使用受控 |
| S4 | 敏感访问会话、导出文件、审计复核 | 审批、限时、强审计、到期销毁或封存 |
