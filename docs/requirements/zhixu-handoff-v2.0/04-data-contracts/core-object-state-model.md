# 核心对象状态机

状态机不是 UI 标签集合，而是业务事实是否可写、可发布、可见、可失效的判断依据。

## 通用跳转规则

1. 草稿到正式必须经过有权角色确认。
2. 正式发布后不得静默覆盖，只能新版本、修正版本或失效标记。
3. 源版本变化必须触发下游当前态失效或待重新确认。
4. 部分成功必须保存对象级状态，不允许只显示整体成功。
5. 归档和停用不删除历史事实。
