# DGV-001 Governance, lifecycle, transfer, export, and data rights PRD v2.0

| 属性 | 值 |
| --- | --- |
| 阶段 | 1 |
| 交付状态 | BUILD_READY |
| 优先级 | P0 |
| 目标 | Make retention, role-separated export, transfer authorization, old-school history, deletion effects, author surrogates, and AI data-use decisions explicit and auditable. |
| 基线决策 | `BASE-001`、`BASE-006` |
| NFR | `NFR-008`、`NFR-009` |
| 进入条件 | the school administrator controls activation governance；data categories and sensitivities are registered |
| 退出条件 | retention periods have explicit school-owned values；student, guardian, teacher, and school exports remain separated and reauthorize generation and download；transfer terminates old-school current access and gives the new school only a source-right-permitted subset；sensitive export and AI use remain blocked while retention is unset |
| 依赖模块 | — |

## 1. 范围与事实边界

- 本模块权威拥有 13 个对象、51 个动作。
- 模块外对象只能以 Object ID、Field ID 和显式源版本引用，不能复制第二套业务事实。
- 页面可见性不是权限边界；每次执行必须按 Action 合同重新判断 ALLOW、DENY、状态和源版本。
- AI 只能查询、分析、生成临时草稿或发起受控动作；不能跳过正式 Action、确认者和审计。

## 11. 研发与测试就绪门禁

- 实现不得发明未登记的 Object、Field、Action、状态、失败码或 Option Set 值。
- 所有选择字段必须调用其 valueSource 指定的静态 Option Set 或授权运行时查询。
- 每个写入动作按 idempotencyKey、对象当前版本、权限、状态和审计模式失败关闭。
- 每个 Scenario 都应转化为可执行测试；失败场景必须验证对象状态不变和越权数据不返回。
- Web/App 只共享事实与权限合同；页面布局和高频能力可以按端差异化。
