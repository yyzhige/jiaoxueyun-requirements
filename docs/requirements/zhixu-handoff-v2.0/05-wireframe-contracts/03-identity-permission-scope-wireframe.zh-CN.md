## 2. App 能力合同

| View ID | 移动视图 | 保留能力 | 不要求移动端承载 | 状态 |
| --- | --- | --- | --- | --- |
| IAM-A01 | 摘要/待办 | 查看当前身份范围、授权到期提醒、高风险动作确认 | 复杂批量表格、长表单配置、跨对象高级筛选 | 必须可用 |
| IAM-A02 | 详情/查看 | 查看本人或授权范围内对象、状态、来源、下一步动作 | 复杂策略编辑 | 必须可用 |
| IAM-A03 | 必要确认 | 低风险确认、移动审批、困难反馈或处理提醒 | 高风险批量写入默认回 Web | 按模块启用 |
| IAM-A04 | AI 对话入口 | 一句话查询、摘要、草稿建议、任务提醒 | 未经预览直接执行写入 | 必须继承 AIX-001 |

## 3. 组件与状态要求

- 筛选控件必须使用字段字典中指定的控件类型和 Option Set。
- 所有列表展示空状态、无权限状态、加载失败状态、部分成功状态和版本过期状态。
- 高风险动作固定展示影响对象数量、源版本、目标版本、确认人和审计摘要。
- AI 结果必须展示数据范围、来源模块、源版本和限制说明。
- App 中被省略的 Web 能力必须显示合理入口或说明，不能让用户以为权限消失。

## 4. 页面级验收

| ID | 验收标准 |
| --- | --- |
| IAM-WF-01 | 页面中出现的选择型字段都能回溯到 Field ID 和 Option Set。 |
| IAM-WF-02 | Web 与 App 的能力差异与 Capability Matrix 一致。 |
| IAM-WF-03 | 无权限、空数据、加载失败、上下文失效、部分成功都有明确状态。 |
| IAM-WF-04 | 高风险确认页在执行前展示影响范围、权限结果和审计摘要。 |
| IAM-WF-05 | AI 对话入口不绕过模块 PRD 的权限、状态和确认门禁。 |
