# 给前端架构师的交接

受众：前端架构与 Web/App 实现团队。

- 第一阶段实现范围只来自 currentReleaseModuleIds：ACC-001 / ORG-001 / IAM-001 / DGV-001 / AUD-001 / CURR-001 / TEA-001 / HW-001 / SUB-001 / SCO-001 / APP-001 / STU-001 / RPT-001 / NOTI-001 / PREP-001 / CONTENT-001 / EXM-001 / SCH-001 / PLAT-001；PLANNED 合同只用于目标评审和后续估算。
- 页面必须逐项引用 Page、Field、Action 与 Option Set；端差异只改变任务呈现，不改变权限和业务事实。
- 发现字段、枚举、权限、状态或失败码缺失时，回到事实模型提出缺陷；不得在实现侧静默发明。
- 第三方渠道和 AI 视频能力不在第一阶段实现范围。
