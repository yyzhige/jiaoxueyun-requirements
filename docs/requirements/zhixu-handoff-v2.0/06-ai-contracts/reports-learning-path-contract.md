# 报表与长期学习路径合同

## 1. 三种时间形态

| 形态 | 定义 | 保存规则 | 示例 |
| --- | --- | --- | --- |
| 临时 | 当前对话或页面即时生成 | 会话内保留，可另存 | 教师问“七1班本周数学作业薄弱点” |
| 定期 | 日/周/月/自定义周期生成 | 保存订阅、快照、源版本、权限结果 | 班主任每日接收本班学习画像摘要 |
| 长期 | 跨学期、学科、知识点、学习活动的持续路径 | 保存事实引用、确认解释、变化时间线 | 学生数学计算能力长期路径 |

## 2. 定期报告规则

1. 订阅前展示周期、时间范围、学生范围、学科范围、指标、接收角色和权限预览。
2. 任课教师订阅本学科，班主任订阅本班跨学科汇总，教务订阅授权汇总。
3. 每次运行重新校验权限，权限失效对象跳过并记录。
4. 报告进入 Web/App 报告中心，站内通知只发送摘要和入口。
5. 第一阶段不向微信、短信、邮件等第三方渠道发送学生明细。

## 3. 长期路径规则

1. 自动进入时间线的事实包括已发布成绩、作业完成、订正结果、计划执行和教师确认记录。
2. 知识点归因、错误模式、能力趋势、下一步建议属于解释性结论。
3. 解释性结论经对应任课教师确认后才对学生展示。
4. 班主任可看本班跨学科摘要和负担协调视图。
5. 长期路径不复制或改写源成绩、证据和计划事实。
