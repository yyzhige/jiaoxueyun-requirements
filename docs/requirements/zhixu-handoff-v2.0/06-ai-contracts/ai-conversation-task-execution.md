# AI 对话、可视化命令与任务执行合同

## 1. 产品定义

第一阶段 AI 能力在 Web/App 内提供，一句话操作、快捷指令和可视化任务执行属于产品交互，不是面向教师、学生或学校人员的终端命令行。

## 2. 能力等级

| 等级 | 定义 | 是否写入 | 门禁 |
| --- | --- | --- | --- |
| 查询 | 返回权限内数据和来源范围 | 否 | 权限和范围校验 |
| 分析 | 生成指标、解释、限制说明 | 否 | 展示来源和不确定性 |
| 临时报表 | 当前会话形成可下钻即时视图 | 否 | 可另存为报告定义 |
| 草稿 | 生成作业、评语、计划、报告定义等草稿 | 草稿 | 有权角色编辑确认 |
| 受控执行 | 修改、发布、订阅等既定任务 | 是 | 结构化预览、二次确认、幂等、审计 |
| 定期任务 | 创建、修改、暂停、取消报告订阅 | 是 | 订阅定义和每次运行权限校验 |

## 3. 执行合同

1. 解析意图时绑定 Active Work Context。
2. 返回候选任务时只展示当前用户可执行任务。
3. 预览必须包含影响对象、字段变化、源版本、目标版本、权限结果、审计摘要。
4. 用户确认后执行目标模块 Flow，不由 AI 直接改写数据。
5. 执行结果保存对象级成功/失败和补偿入口。
6. 学校、身份、学期、权限或源版本变化后，预览失效。
