# 需求包审查清单

| 检查项 | 通过标准 |
| --- | --- |
| 产品目标 | 每个模块服务主教学闭环或明确登记为后续扩展 |
| Data ID | 每个权威对象有唯一 Data ID 和业务 Owner |
| 字段 | 每个选择型字段有 Field ID、控件、Option Set、默认和失效规则 |
| 状态 | 对象状态有合法跳转和阻断条件 |
| 权限 | 角色、职责、数据范围、字段级限制清晰 |
| Flow | 跨模块流转有源版本、目标版本、幂等、失败和补偿 |
| AI | AI 不成为正式事实 Owner，写入动作有预览、确认、审计 |
| Web/App | 端能力差异在 Capability Matrix 登记 |
| 验收 | 每个模块验收标准可测试 |
| 第二阶段 | 第三方通知与视频生成只登记不展开 |
